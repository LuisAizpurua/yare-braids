## 💇‍♀️ Catálogo de Peinados y Precios

Aplicación web moderna para la **visualización y consulta de estilos de peinados**, diseñada para presentar una galería de servicios junto con sus respectivos precios de forma clara, rápida y atractiva.

Construida con **Astro.js**, **Tailwind CSS** y **Turso Cloud**, priorizando rendimiento, experiencia de usuario y diseño responsive.

## ✨ Características

### 🎨 Diseño moderno

Interfaz limpia y elegante desarrollada con **Tailwind CSS**, enfocada en ofrecer una experiencia visual atractiva y sencilla.

### ⚡ Alto rendimiento

Construido con **Astro.js** para aprovechar su arquitectura orientada al contenido y generar páginas rápidas y optimizadas.

### 🗄️ Base de datos

Integración con **Turso Cloud** para almacenar y gestionar la información relacionada con los servicios y precios.

### 📱 Diseño responsive

La interfaz se adapta a diferentes tamaños de pantalla:

* 📱 Smartphones
* 📲 Tablets
* 💻 Laptops
* 🖥️ Desktop

### 🖼️ Galería de estilos

Catálogo visual de diferentes estilos de peinados, permitiendo presentar cada servicio de manera organizada.

### 💰 Catálogo de precios

Visualización clara de los servicios disponibles y sus respectivos precios.

### 🔍 Búsqueda y filtros

Herramientas para facilitar la búsqueda y navegación dentro del catálogo.

## 🚀 Instalación

Clona el repositorio:

```bash
git clone <repository-url>
```

Accede al proyecto:

```bash
cd <project-folder>
```

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm run dev
```

La aplicación estará disponible normalmente en:

```text
http://localhost:4321
```

---

## 📦 Build para producción

Genera la versión optimizada:

```bash
npm run build
```

Previsualiza el build:

```bash
npm run preview
```
